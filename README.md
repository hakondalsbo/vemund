## Publisering med GitHub Pages

1. Gå til repoet på GitHub.
2. Åpne `assets`-mappen og last opp alle bildefilene over.
3. Trykk `Commit changes`.
4. Gå til `Settings` -> `Pages`.
5. Velg `Deploy from a branch`.
6. Velg branch `main` og folder `/ (root)`.
7. Trykk `Save`.
